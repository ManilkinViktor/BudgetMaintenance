# Budget Maintenance

Веб-приложение на Django для учета личного бюджета: кошельки, категории, транзакции и статистика.

**Возможности**
- Регистрация, вход и выход пользователей.
- Кошельки: создание, редактирование, удаление.
- Категории доходов и расходов: создание, редактирование, удаление.
- Транзакции с датой и комментарием, автоматическое обновление баланса кошелька.
- Сводка за текущий месяц на главной странице.
- Статистика по доходам/расходам за период с фильтром по кошелькам.

**Стек**
- Python 3.12
- Django 5.2
- PostgreSQL (в `docker-compose.yml` используется образ `postgres:14.8-alpine3.18`)

**Запуск**
1. Установите зависимости: `pipenv install`
2. Подготовьте базу данных (см. раздел "База данных").
3. Примените миграции: `pipenv run python manage.py migrate`
4. Создайте суперпользователя (опционально): `pipenv run python manage.py createsuperuser`
5. Запустите сервер: `pipenv run python manage.py runserver`

**База данных**
1. Docker Compose: перейдите в `database` и выполните `docker compose up -d`.
2. Локальный PostgreSQL: используйте параметры из `project/settings.py` (по умолчанию `db/db/12345`, `localhost:5432`) или измените их под свою среду.


**Маршруты**
- `/` — главная страница со сводкой.
- `/signup/` — регистрация.
- `/login/` — вход.
- `/logout/` — выход.
- `/wallets/` — кошельки.
- `/categories/` — категории.
- `/transactions/` — транзакции.
- `/stats/` — статистика.
- `/admin/` — админка Django.

**Примечания по логике**
- При регистрации автоматически создаются категории по умолчанию для доходов и расходов.
- Изменение/удаление транзакции корректно пересчитывает баланс кошелька.
